# Работа над дизайном

Эта папка содержит текущую теоретическую модель KRP. Сейчас проект не переходит к реализации, прототипам или плейтестам: дизайн развивается через причинный анализ, сценарии и thought experiments.

Системные документы, включая [специализацию](specialization.md), [экономику](economy-and-resources.md), [инвентарь](inventory-and-item-logistics.md), [строительство](construction.md), [бой и смерть](combat-and-death.md), [собственность](ownership-and-infrastructure.md), [камеру](camera-and-perspective.md) и [королевства](kingdoms-and-local-cooperation.md), — текущее описание отдельных частей игры.

## Статусы

- **Принято** — используется как основание текущей теоретической модели. Это не означает эмпирического подтверждения.
- **Гипотеза** — перспективное объяснение или механика, которую ещё нужно проверить на сценариях и противоречиях.
- **Открыто** — существует несколько существенно разных механических вариантов.
- **Отброшено** — вариант противоречит столпам или создаёт неприемлемые системные последствия.
- **Баланс / данные** — числа, рецепты, длительности, коэффициенты и наборы контента, не меняющие игровой цикл.
- **Исследование** — внешний контекст, который помогает рассуждать, но сам по себе не задаёт правило игры.

## Правило итерации

Одна итерация отвечает на один вопрос:

```text
вопрос -> варианты -> причинные цепочки -> сценарии 7 / 20 / 70
       -> злоупотребления и пограничные случаи -> решение или сохранение вопроса
```

В канон попадает только выбранное правило и его необходимые последствия. Аргументация остаётся в thought experiment, а краткий итог — в журнале решений.
